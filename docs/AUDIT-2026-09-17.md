## Achados e tratamento

| Achado | Tratamento |
| --- | --- |
| README dizia API desativada, contradizendo o handoff posterior | README atual e histórico preservado em RUNTIME-LEGACY; banners nos documentos antigos |
| Sem CI, apesar do gate explícito no Sprint 0 | Workflow de lint/typecheck, contratos, Prisma, testes e build |
| Instalação documentava npm ci, mas havia apenas lockfile pnpm e script Bash | Comando único de instalação pnpm congelada, portable |

| Lint inicial apontou dois links internos e dois efeitos de sincronização | Links usam Next Link; duas exceções locais documentadas preservam carga de memberships e limpeza na troca de tenant, sem desativar a regra globalmente |

| Importação CSV só em memória | Issue #3 com critérios de persistência/idempotência/isolamento |

## Plano aplicado

Concluir primeiro a automação de fundação já prevista nas seções 17 e 19.1 da especificação, centralizar documentação e rastrear a continuação por issues. Isso reduz a chance de introduzir persistência sobre uma base sem validação contínua. Ver [ADR-003](DECISIONS.md).

## Evidências e limites

Instalação congelada concluída com 736 pacotes, preservando lockfile e políticas. O check dos cinco contratos passou e seu teste de regressão confirmou que drift é rejeitado sem reescrita, inclusive com CRLF.

Validação local: 40 testes de domínio/CSV/telefones/contratos e 29 testes de backend/PostgreSQL passaram; Prisma validou o schema e confirmou 324 entradas equivalentes. Build portable concluído. Resultados finais de lint/typecheck e CI são registrados no PR e no Actions correspondente. A auditoria não modificou banco, segredos, memberships ou Site publicado; não confirma disponibilidade remota, backup, autenticação E2E ou aptidão comercial. Nenhum dado real foi importado.
